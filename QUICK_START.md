## Now Do This:

### 1️⃣ Push to GitHub (ONE TIME)

```bash
cd agents-saas
git init
git add .
git commit -m "Initial"
git branch -M main
git remote add origin https://github.com/tgarot559/agents-saas.git
git push -u origin main
```

### 2️⃣ Deploy to Vercel (ONE TIME)

1. Go to https://vercel.com
2. Click "Add New..." → "Project"
3. Select "agents-saas" repo from GitHub
4. Click "Import"
5. Environment variables already set ✅
6. Click "Deploy"
7. **Done!** 🎉

### 3️⃣ Access Your Platform

**URL:** `https://agents-saas.vercel.app`  
**Admin Email:** thierry@example.com  
**Admin Password:** (any password you set during registration)  

### 4️⃣ Create a Client

1. Login as admin
2. "Add Client" button
3. Fill name + email
4. Click "Invite"
5. Share invite code with client

### 5️⃣ Client Login

Client registers with the invite code you gave them.  
They see three apps: LinkedIn, Social, Prospection.
